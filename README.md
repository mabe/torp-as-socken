# Torp i Ås Socken

GitHub Pages-webbplats för att redovisa resultatet av studiecirkeln inom
Veddige–Ås–Sällstorp hembygdsförening om inventering av gamla torp i Ås socken.

Webbplatsen publiceras på: <https://mabe.github.io/torp-as-socken>

## Lokal utveckling

```bash
bundle install
bundle exec jekyll serve
```
